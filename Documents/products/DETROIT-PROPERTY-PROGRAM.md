# Detroit Property & Program

**Status:** Pilot / concept — HQ source of truth  
**HQ route:** `/hq/detroit`  
**API:** `/api/hq/detroit-workspace` (Founder/HQ session required)

One phone-friendly workspace for Detroit land-bank property research, program design, and grant tracking. Records persist in HQ SQLite so signed-in devices share the same data.

## Work areas

Properties, eligibility checklist, lot comparison, site notes, work plans, budgets, contacts, applications, follow-ups.

Unverified amounts, eligibility, and availability stay **Unknown**. Do not invent grant awards.

## Grant Center

Applications can link to existing Grant Center opportunities/applications and can save research into Grant Center when a funder name is known. Aura is **not** running a live Detroit grant search from this page.

## Legacy Site

The ChatGPT Detroit research Site is not the system of record. Import from this browser or pasted JSON is additive only: duplicates are skipped, HQ records are never overwritten or discarded.

## Gates

No Land Bank contact, application submission, property purchase, or fund commitment from this workspace.
